# XML 字段与 DOC 模板的映射差异

## 总览

XML 存储格式（副本.xml）有 34 个独立字段。DOC 打印模板（任免表.doc → .docx）有合并单元格，
部分格子里塞了多个字段的取值来源。

## 差异点：教育栏

XML 有 8 个教育字段，DOC 只有 4 个合并格。

| DOC 合并格 | 对应 XML 字段 | 导出策略 |
|---|---|---|
| 全日制—学历/学位 | `QuanRiZhiJiaoYu_XueLi` + `QuanRiZhiJiaoYu_XueWei` | 拼接为 `{XueLi} / {XueWei}` |
| 全日制—毕业院校系及专业 | `QuanRiZhiJiaoYu_XueLi_BiYeYuanXiaoXi` + `QuanRiZhiJiaoYu_XueWei_BiYeYuanXiaoXi` | 拼接为 `{XueLi院校} / {XueWei院校}` |
| 在职—学历/学位 | `ZaiZhiJiaoYu_XueLi` + `ZaiZhiJiaoYu_XueWei` | 同上 |
| 在职—毕业院校系及专业 | `ZaiZhiJiaoYu_XueLi_BiYeYuanXiaoXi` + `ZaiZhiJiaoYu_XueWei_BiYeYuanXiaoXi` | 同上 |

## 其余 26 个字段

XML 和 DOC 一一对应，无差异。按占位符 `{字段名}` 直接注入。

## 家庭成员

DOC 模板表格有 1 行表头 + 多行数据行。`docxtemplater` 用 `{#JiaTingChengYuan.Item}{ChengWei}...{/JiaTingChengYuan.Item}` 循环语法生成多行。
XML 存档中 JiaTingChengYuan.Item 为可变数组，导出时取 store 实际行数。

## 证件照

DOC 模板中照片区域不填占位符，导出时跳过。如需嵌图，需额外使用 docxtemplater-image-module 或手动操作 docx zip 内的 word/media/。
