# XML 字段与 DOC 模板的映射差异

## 总览

XML 存储格式（副本.xml）有 34 个独立字段。DOC 打印模板（任免表.doc -> .docx）有合并单元格，
部分格子里塞了多个字段的取值来源。

## 差异点：教育栏

XML 有 8 个教育字段，DOC 只有 4 个合并格。

| DOC 合并格 | 对应 XML 字段 | 导出策略 |
|---|---|---|
| 全日制-学历/学位 | `QuanRiZhiJiaoYu_XueLi` + `QuanRiZhiJiaoYu_XueWei` | 拼接为 `{XueLi} / {XueWei}` |
| 全日制-毕业院校系及专业 | `QuanRiZhiJiaoYu_XueLi_BiYeYuanXiaoXi` + `QuanRiZhiJiaoYu_XueWei_BiYeYuanXiaoXi` | 拼接 |
| 在职-学历/学位 | `ZaiZhiJiaoYu_XueLi` + `ZaiZhiJiaoYu_XueWei` | 同上 |
| 在职-毕业院校系及专业 | `ZaiZhiJiaoYu_XueLi_BiYeYuanXiaoXi` + `ZaiZhiJiaoYu_XueWei_BiYeYuanXiaoXi` | 同上 |

## 差异点：家庭成员年龄

DOC 模板里是"年 龄"格，XML 存的是 `ChuShengRiQi`。
导出时由 IPC handler 计算年龄：`ChuShengRiQi` + `JiSuanNianLingShiJian` -> 年数 -> 注入模板。

## 差异点：填表时间

DOC 模板是分开的"年" "月" "日"三个独立格，XML 存的是 `TianBiaoShiJian`。
导出时解析 `TianBiaoShiJian`（如 `2026.06.20`）-> `.split('.')` -> 分别注入。

## 差异点：身份证号

DOC 模板中**不存在**身份证号栏目。导出时跳过不填。

## 其余字段

XML 和 DOC 一一对应，无差异。按占位符 `{字段名}` 直接注入。

## 家庭成员

DOC 模板表格有 1 行表头 + 多行数据行。`docxtemplater` 用循环语法 `{#Item}{ChengWei}...{/Item}` 生成多行。
XML 存档中 JiaTingChengYuan.Item 为可变数组，导出时取 store 实际行数。

## 证件照

DOC 模板中照片区域不填占位符，导出时跳过。
